## Unnecessary / purposeless UI

Remove or redesign:

1. **Fill mode “Retry fill”** — identical to “Fill with resume”; drop or give distinct semantics.
2. **Skip PartyRock (no PDF)** checkbox when **PartyRock header toggle is already OFF** — redundant.
3. **Ops `hybridFillDummy` + `/hybrid_fill_dummy` button path** — unused in primary UI; classic dual Start/Fast fill should collapse to one.
4. **`primaryAction()`** — unused; delete or wire.
5. **Pipeline filter Cancelled / Skipped** — useless until Skipped queue is reachable.
6. **Mission-stat gap** — add Skipped (or kill skip/cancel statuses from product) so Cancel/Skip aren’t black holes.
7. **Classic Fast fill** when PartyRock-off Start already does fill-only.
8. **Second Empty Deleted** (filters vs prune).
9. **`has_description` / `lazy` chip** — not user-facing.
10. **`/classic` long-term** — or freeze classic and document Ops-only; dual UX is the root of Start vs Fill wording lies.
11. **`dossier_mock.html` / dead hybrid naming** (`hybrid_fill_dummy` engine label when `fast_fill` always wins).
12. **Ops Skip-no-PDF in Real Mode** — disabled checkbox that only says “Test Mode only” (noise).
13. **Classic Restore + Retry both primary on cancelled** — pick one recovery path.
