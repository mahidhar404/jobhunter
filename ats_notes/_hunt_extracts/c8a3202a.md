## New FILL3 findings

### FILL3-001 — High — Dashboard Flash+hold+refill silently kills Skyvern; verdict may still FAIL as “Flash failed”
- **Location:** `dashboard/server.py` (~3823–3828); `fast_fill.py` ~9971–9993; `page_progress.flash_attempt_failed` ~392–417
- **Manifestation:** Dashboard headed Start/Fast fill → `--flash-leftovers --hold-open --refill-passes 2`. Skyvern path skipped (`skyvern_deferred`). If leftovers remain and inpage `invoked=false` (deterministic-only / no LLM attempt), `flash_attempt_failed` → `verdict_reason=flash_leftovers_failed`.
- **Cause:** Defer condition `hold_is_active OR refill_passes>0` vs fail rule `not flash.get("invoked")` with no `skyvern_deferred` exemption.
- **Confidence:** High

### FILL3-002 — High — Pause overlay can cover / intercept CAPTCHA clicks

- **Manifestation:** Human told to solve CAPTCHA in browser; Pause/Continue sits top-right at near-max z-index and keeps receiving clicks; CAPTCHA widgets often share that corner.
- **Cause:** Overlay always-on for headed fill; never lowered/hidden while `page_shows_interactive_captcha` or captcha wait active.
- **Confidence:** High (S03 upgrade with use-case)

## Unnecessary complexity / dead paths

1. **Dual Flash stack (inpage + Skyvern)** — Skyvern almost never runs on the primary dashboard path (hold+refill). Large `run_flash_leftovers` / Skyvern machinery is effectively dead for that use case; complexity remains in gates (`flash_attempt_failed`, scorecard).
2. **`looks_like_gap_message`** — defined, unused; gap filter was designed then abandoned.
3. **`--no-refill-wait-enter`** — default already off; flag is backward-compat dead weight.
4. **`force_row` in inpage Flash** — computed then `_ = force_row  # reserved` — dead.
5. **Hybrid fill** — refused when Playwright `fast_fill` exists; fallback path rarely hit but still documented/branched in dashboard.
6. **Matrix smoke** — forces `flash_leftovers=False` while dashboard production path forces True — divergent “coverage” story.
7. **Multiple demote oracles** — `_demote_filled_against_required_empty`, vision empties, form_gaps, leftover_miss_scan, unanswered_choices — overlapping honesty layers that amplify refill thrash.
8. **Two continue sentinels + Pause overlay + CAPTCHA Enter** — three human-resume channels without a unified gate state machine.
9. **Ashby zip candidate selector list** — long scroll/wait matrix; early “absent” short-circuit undercuts it (FILL3-005).
