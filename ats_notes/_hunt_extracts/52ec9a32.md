## New bugs (ATS3-…)

### Critical / High

**ATS3-001** · **High** · Ashby Location false-commit from display match alone  
- **Location:** `ashby_widgets.py` `fill_ashby_location_then_zip` ~659–667  
- **Manifestation:** Filter shows `Springfield, Illinois, United States` without list pick → `committed=True` → zip wait fails → leftover / Flash zip; thrash or silent incomplete  
- **Cause:** After failed/partial autocomplete, `location_display_matches(shown)` forces commit without `option_clicked` / `dependent_revealed` (contradicts skip guard at ~612–614)  
- **Confidence:** High  

**ATS3-002** · **High** · `_ashby_zip_field_present` conflates “input not mounted” with “zip N/A”  
- **Location:** `ashby_widgets.py` ~289–298, early exit ~552–565; demote path `fast_fill.py` ~3317–3321  
- **Manifestation:** HTML has “home zip” but input not ready in 1.5s → `zip_field_absent_on_form` / skip Location→zip; user sees blank zip  
- **Cause:** Requires `_html_has_ashby_zip_question` **and** `_wait_ashby_zip_input(timeout_ms=1500)`; dependent fields often mount only after Location commit  
- **Confidence:** High  

**ATS3-003** · **High** · Generic ADVANCE marks `stuck_on_same_page` on intentional FAIL-before-ADVANCE  
- **Location:** `fast_fill.py` `try_advance_if_page_complete` ~4207–4219; `page_progress.compute_stuck_on_same_page` ~147–168 (sticky OR at ~219–221)  
- **Manifestation:** Required empties + visible Next → stuck flag sticky → Ready/SUCCESS demotion; multipage walk aborted even when refusal was correct. WD `_gate_then_advance` correctly passes `next_existed=False` (~4080–4085); generic path does not  
- **Cause:** `compute_stuck_on_same_page` treats `next_existed && unchanged fingerprint` as stuck without requiring `advance_clicked`  
- **Confidence:** High  

**ATS3-004** · **High** · Fiber click-then-reject leaves wrong option committed  
- **Location:** `verified_select.py` `_FIBER_SEARCH_SELECT_JS` ~907–908; Python post-check ~978–1004  
- **Manifestation:** Wrong state/dial briefly selected; Escape often fails to undo Workday/GH commit → wrong select sticks or thrash reopen  
- **Cause:** JS `best.o.click()` runs before Python confusable/dial reject; reject only sets status + Escape  
- **Confidence:** High  

**ATS3-005** · **High** · `soft_value_match` still has Male⊂Female (FILL2-001 incomplete)  
- **Location:** `verified_select.py` `soft_value_match` ~103–127 (`_SHORT_TOKEN_MAX=3`); used by Ashby `_value_already_correct`, WD soft paths, `option_mappings`  
- **Manifestation:** Gender already-correct skip or soft accept when UI shows Female and intent is Male (or reverse thrash)  
- **Cause:** Tokens length ≥4 use bidirectional `"male" in "female"`; GH `_score_option` was fixed, shared soft matcher was not  
- **Confidence:** High
